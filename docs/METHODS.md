# Scope and implementation

Bounded explicit neutral atom/integer-bond graphs. Computes component count, graph cycle rank, explicit-atom formula, within-component Wiener sum and permutation-invariant local descriptor counts; checks declared valence upper bounds. No implicit hydrogens, aromaticity, charges, stereochemistry, canonical isomorphism, energetics, synthesis, molecular validity or medical inference.

The code implements a bounded reference method, not a new universal theory. Source and method versions, declared inputs and explicit limitations must accompany downstream claims. Domain test success does not substitute for independent reproduction. Changes to captured evidence reopen dependent claims through the ResearchOS controller.
